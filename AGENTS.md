# StayBook project instructions

- Scope: Online Booking only. PMS/front desk, housekeeping/maintenance, POS and HR/payroll belong to other team members. Keep future connections as TODO comments and README plans until the user asks to implement integration.
- Keep the existing XianFire framework, `.xian` templates and Tailwind CSS.
- Do not treat login or registration examples as requests to implement those features.
- Connect only to this module's own booking database. Do not modify the other systems' databases or present a local booking as PMS-confirmed.
- Finish and verify each coherent feature, then commit it before starting another feature. Group related source, UI, tests and feature documentation in that feature's commit. Do not fabricate earlier commits or rewrite existing history.
- Review staged paths and exclude `.env`, credentials, dependencies, runtime data and generated screenshots.
- The user authorizes local feature commits. Push only when the user asks for publication/pushing.
